# Contributing to ARY-Tech-Group Developer Portfolio

Thanks for your interest in contributing!

## Before you start

1. Search existing Issues to avoid duplicate work.
2. For a large change, open an Issue first to discuss the approach.
3. Be respectful and follow our Code of Conduct.

## Suggested workflow

1. Fork the repository or create a branch if you have collaborator access.
2. Create a focused branch, for example `fix/mobile-navigation`.
3. Make a small, clear change.
4. Test the page on desktop and mobile widths.
5. Check keyboard navigation and browser console errors.
6. Commit with a clear message, such as `Fix mobile navigation state`.
7. Open a pull request explaining what changed and how you tested it.

## Pull request checklist

- [ ] The change addresses an existing Issue or explains its purpose.
- [ ] The page still works on mobile and desktop.
- [ ] Links and buttons work.
- [ ] Keyboard focus is visible.
- [ ] No unrelated files or generated assets were added.
- [ ] Documentation is updated if needed.

## Good first issues

Look for Issues labelled `good first issue`, `help wanted`, or `documentation`. If you are unsure, ask a question in the Issue before starting work.
