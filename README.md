# ARY-Tech-Group Developer Portfolio Starter

A beginner-friendly, responsive developer portfolio website built with plain HTML, CSS, and JavaScript. It is intended as a real starter project that ARY-Tech-Group can improve in public with community contributions.

## Current features

- Responsive layout for desktop and mobile
- About, projects, skills, and contact sections
- Mobile navigation menu
- Accessible focus styles and semantic page sections
- No build tools or third-party dependencies required

## Run locally

1. Clone this repository:
   ```bash
   git clone https://github.com/ARY-Tech-Group/ary-developer-portfolio.git
   ```
2. Open the folder.
3. Open `index.html` in your browser.

For a better development experience, use Visual Studio Code with the Live Server extension, or run a local static server if you already have one installed.

## Customize it

1. Replace `Your Name`, the sample biography, skills, and project descriptions in `index.html`.
2. Replace `hello@example.com` with a real contact email, or remove the email button.
3. Replace example project links with real repository or demo links.
4. Add real projects as they become available. Do not describe planned projects as completed work.
5. Adjust colors and spacing in the CSS variables at the top of `styles.css`.
